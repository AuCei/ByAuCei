# 阿张的小破站 · 云端留言板版

本版本已将留言板从浏览器本地存储升级为 Cloudflare Workers + D1 云端后端。

## 主要能力

- 所有访客共享留言
- 云端保存留言与点赞
- 发布、搜索、排序、点赞、取消点赞
- 发布者凭删除令牌删除自己的留言
- 管理员密钥删除任意留言
- 服务端字段校验和基础频率限制
- 当前允许所有域名访问，便于开发测试
- 保留留言板入口、下拉菜单修复和点赞无淡出效果
- 复制邮箱功能保持删除，邮件发送入口继续保留

## 部署

请先阅读 `backend/README.md`，部署 Worker 后再修改 `guestbook-config.js` 中的 API 地址。
